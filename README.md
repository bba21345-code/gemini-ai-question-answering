# AI-Powered Question Answering System Using Google Gemini

## About
This project uses Google's Gemini generative AI model to answer questions through Python.

## Technologies Used
- Python
- Google Gemini API
- Google Colab
- Google Gen AI SDK

## Features
- Sends questions to Gemini AI
- Generates AI-powered text responses
- Runs in Google Colab

## How to Run
1. Open the notebook in Google Colab.
2. Install the `google-genai` package.
3. Add your `GEMINI_API_KEY` to Colab Secrets.
4. Run the notebook cells.
5. Enter a question and view the AI-generated response.

## Security
Never upload your API key or other private credentials to GitHub.
